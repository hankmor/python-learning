# Python教程37：抽象基类（ABC） - 练习题

## 练习题

### 1. Vehicle抽象基类
创建一个Vehicle抽象基类，定义交通工具的基本接口（start, stop, drive等），然后实现Car和Bicycle子类。

### 2. 文件处理器抽象类
实现一个FileProcessor抽象类，定义read()和write()方法，然后创建TxtProcessor、CSVProcessor、JSONProcessor子类。

### 3. Logger接口
设计一个日志系统，使用ABC定义Logger抽象接口，实现ConsoleLogger和FileLogger。

## 思考题
