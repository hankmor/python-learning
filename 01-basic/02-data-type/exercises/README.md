# 练习题

## 第1题：除法运算对比

计算`9 / 2`、`9 // 2`、`9 % 2`的结果，理解它们的区别

**要求**：
- 分别打印三个运算的结果
- 观察结果类型差异
- 理解除法、整除、取模的区别

## 第2题：浮点数精度问题

尝试`print(0.1 + 0.2)`，看看浮点数精度问题

**要求**：
- 观察输出结果
- 尝试用`round()`函数解决
- 理解为什么会出现这个问题

## 第3题：圆的面积计算

写一个程序，输入圆的半径，计算并输出圆的面积（π取3.14）

**要求**：
- 获取用户输入的半径
- 使用公式：面积 = π × r²
- 输出计算结果

**提示**：`r²`可以用`r ** 2`表示
