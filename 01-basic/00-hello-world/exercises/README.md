# 练习题

## 第1题：验证Python安装

在你的电脑上安装Python 3，并运行`python3 --version`验证安装

**提示**：
- Windows用户可能是`python --version`
- 确保版本号显示为3.x

## 第2题：个性化问候程序

创建一个`my_first_program.py`文件，打印你的名字和一句你喜欢的诗词

**要求**：
- 至少打印两行
- 包含你的名字
- 包含一句诗词或名言

## 第3题：阅读Python之禅

在Python交互式环境中输入`import this`，阅读《Python之禅》

**思考**：
- 你最喜欢哪一句？
- 为什么？
