# 练习题

## 第1题：年龄计算器

写一个程序，获取用户的姓名和出生年份，计算并输出用户的年龄

**要求**：
- 使用`input()`获取用户输入
- 正确进行类型转换
- 输出包含姓名和年龄

## 第2题：测试非法变量名

尝试给变量取一些不合法的名字（如`1name`、`user-name`），看看会报什么错

**目的**：
- 理解变量命名规则
- 熟悉Python的错误提示

## 第3题：长方形面积计算

写一个程序，计算长方形的面积，长和宽由用户输入

**要求**：
- 获取长和宽
- 计算面积
- 输出结果

**提示**：记得类型转换（`float()`）
