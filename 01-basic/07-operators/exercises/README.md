# 练习题

## 第1题：表达式计算

计算表达式：`10 + 5 * 2 ** 2 - 8 // 3`的结果，并说明计算顺序

**要求**：
- 写出每一步的计算过程
- 解释运算符的优先级

## 第2题：链式比较

写一个程序，判断一个数是否在10到100之间（包含10和100），使用链式比较

**要求**：
- 获取用户输入
- 使用链式比较（形如 `10 <= x <= 100`）
- 输出判断结果

## 第3题：`==`和`is`的区别

解释`==`和`is`的区别，并举例说明

**要求**：
- 写代码演示两者的区别
- 解释什么时候用`==`，什么时候用`is`

## 第4题：短路求值应用

利用短路求值特性，写一个安全的除法函数

**要求**：
- 检查除数是否为0
- 使用逻辑运算符的短路特性
- 避免除零错误
